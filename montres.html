Partage à deux

Les montres se synchronisent automatiquement entre vos appareils.
Première fois ? Il faut créer le coffre une seule fois, sur un seul compte Google :
  1. Nouveau Google Sheet ▸ menu Extensions ▸ Apps Script
  2. Collez le fichier apps-script-montres.gs du dépôt, choisissez un mot de passe dans TOKEN
  3. Déployer ▸ Application Web ▸ exécuter en tant que moi, accès tout le monde
  4. Copiez l'adresse en /exec et collez-la ci-dessous
Ensuite, bouton Lien de partage : l'autre personne n'a plus qu'à ouvrir le lien.
